# Salesbot — Телеграм-бот приёма заказов на хлеб

## Быстрый старт

### 1. Установите зависимости

```bash
pip install -r requirements.txt
```

### 2. Заполните конфиг-файлы

| Файл | Что вписать |
|------|-------------|
| `config/token.txt` | Токен бота от @BotFather |
| `config/admins.txt` | Telegram ID администраторов (по одному на строку) |
| `config/group.txt` | ID группы-уведомлений (отрицательное число, например `-1001234567890`) |

**Как узнать ID группы:** добавьте бота в группу, отправьте любое сообщение, затем откройте `https://api.telegram.org/bot<TOKEN>/getUpdates` и найдите `"chat":{"id":...}`.

### 3. Заполните ассортимент

Отредактируйте `data/bread.csv` — каждая строка: `Название,цена`

```
Бородинский,150
Ржаной,120
Пшеничный,100
```

### 4. Запустите бота

```bash
python bot.py
```

При запуске бот автоматически заполнит `data/calendar.json` датами на 4 недели вперёд (среды и субботы).

## Команды администратора (только из группы)

| Команда | Описание |
|---------|----------|
| `/dateadd YYYYMMDD` | Добавить дату в календарь |
| `/dateremove YYYYMMDD` | Удалить дату из календаря |
| `/datedisplay` | Показать 6 ближайших дат |
| `/breadadd Название, цена` | Добавить хлеб |
| `/breadremove Название` | Удалить хлеб |
| `/breadlist` | Показать ассортимент |
| `/help` | Справка |
